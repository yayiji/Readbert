# VS-Dilbert

A web app for browsing the complete Dilbert comic strip archive (1989–2023) with AI-powered transcriptions, full-text search, and bookmarks.

## Features

- **Full Archive** — Browse all 13,000+ strips from April 16, 1989 to March 12, 2023
- **AI Transcriptions** — Every comic has a panel-by-panel transcription generated by Google Gemini
- **Full-Text Search** — Cmd/Ctrl+K command palette to search across all transcripts
- **Bookmarks & History** — Save favorites and pick up where you left off
- **Date Picker** — Jump to any date with a calendar widget
- **Random Comic** — Discover strips at random with image preloading
- **Keyboard Navigation** — Arrow keys and shortcuts for quick browsing
- **Offline-Friendly** — Multi-tier caching with IndexedDB, CDN, and local fallbacks

## Tech Stack

- **SvelteKit 2** with **Svelte 5** (runes-based reactivity)
- **Vite 7**
- **IndexedDB** (via `idb`) for client-side persistence
- **Google Gemini / OpenRouter** for AI transcription
